SETUP

1. Copy README.md, assets/, scripts/, and .github/ into your GitHub profile repository.
2. Your profile repository should have the same name as your GitHub username.
3. Push everything to main.
4. Open GitHub Actions -> Update README activity -> Run workflow once.
5. The action replaces assets/activity.svg with your live animated contribution graph.

Design notes:
- The visual system follows a Linear/Vercel direction: near-black surfaces, cool white type, precise borders, and a restrained violet accent.
- Fine grid lines, compact labels, and product diagrams create hierarchy without decorative noise.
- The README stays tiny; the visual design lives inside custom SVGs to work within GitHub's CSS limits.
